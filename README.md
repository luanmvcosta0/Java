# ☕ Java — Fundamentos e Lógica de Programação

Repositório com meus estudos dos **fundamentos da linguagem Java**: lógica de programação, estruturas de controle, vetores, métodos e os pilares da Programação Orientada a Objetos. Cada pacote agrupa um tema, com exemplos comentados e pequenos programas de prática.

> 📚 **Status:** repositório de estudos — marca o início da minha jornada com Java, base que hoje aplico profissionalmente com Spring Boot.

## 📂 Organização do projeto

Todo o código-fonte está em `LogicaJava/src/`, dividido por temas:

| Pacote | Conteúdo |
|--------|----------|
| `Exemplos/` | Sintaxe da linguagem: variáveis, constantes, tipos, operadores (aritméticos, lógicos, relacionais, de atribuição), `if/else`, `switch`, laços `for` e `while`, vetores de 1, 2 e N dimensões, métodos com parâmetros e retorno |
| `ProgramasCriados/` | Programas de prática: calculadora, cálculo de IMC, troco, bônus de funcionário, desconto de frete, contas a pagar, cadastro de tarefas do dia, divisibilidade, aprovação em concurso/ano letivo, entre outros |
| `ExerciciosInternet/` | Exercícios de fixação encontrados na internet |
| `primeiraClasse/` | Primeiro contato com classes e objetos |
| `encapsulamento/` | Pilar do encapsulamento: atributos privados, getters e setters |
| `metodoInstancia/` | Métodos de instância e manipulação de objetos |
| `exercicioComMetodos/` | Exercício integrando classes (`Produto`, `Pedido`) com regras como reposição de estoque |
| `poo/` | POO na prática: herança e polimorfismo com `Veiculo` → `Carro`, e modelagem de um `Personagem` |
| `teste/` | Classes de modelagem e teste (`Aluno`, `Carro`, `Produto`) |

## 🛠️ Tecnologias

- **Java** (JDK 17+ recomendado)
- **IntelliJ IDEA** — IDE utilizada no projeto

## 🚀 Como rodar

1. Clone o repositório:

```bash
git clone https://github.com/luanmvcosta0/Java.git
```

2. Abra a pasta `LogicaJava` no IntelliJ IDEA (ou na IDE de sua preferência).

3. Cada arquivo com método `main` pode ser executado individualmente — basta abrir a classe desejada e rodar.

Ou, pelo terminal:

```bash
cd Java/LogicaJava/src
javac ProgramasCriados/Calculadora.java
java ProgramasCriados.Calculadora
```
